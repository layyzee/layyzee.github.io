# Balaji Palani - Senior Scrum Master Portfolio Website

A sleek, responsive, executive-tier portfolio website for **Balaji Palani** (Senior Scrum Master & Agile Delivery Leader with CSM® and SAFe® 6 SSM credentials).

## 🚀 Features

- **Executive Tech Aesthetics:** Dark & Light mode toggle with smooth glassmorphism design.
- **Quantifiable Impact Dashboard:** Highlights key metrics (+20% Sprint Velocity, -40% Blockers, -30% Planning Time, 10 to 3 Story Spillover reduction).
- **Interactive Experience Timeline:** Detailed breakdowns for MITS Global Consulting (BFSI/FinTech), Incedo Inc (Verizon Telecom), CDP360 Technologies, and Azure Soft Tech Solutions (Frontend & AWS foundation).
- **Skills Matrix:** Categorized into Agile & Delivery, Coaching & Leadership, Tools & Platforms (Jira, Power BI, Confluence, Azure DevOps), and Technical Roots (React, AWS).
- **Accredited Badges:** Scrum Alliance CSM and Scaled Agile SAFe 6 SSM.
- **Direct Contact System:** 1-click clipboard copy for email and phone, dynamic mailto form, and LinkedIn connection.
- **Print / PDF Friendly:** Click "Save / Print PDF" to export a clean, high-impact resume.
- **Zero Dependencies:** Pure HTML5, CSS3, and modern JavaScript. No npm installs or build steps needed.

## 🌐 Deploy to GitHub Pages for Free (1-Minute Guide)

You can publish this completely free forever with GitHub Pages:

### Step 1: Create a New GitHub Repository
1. Go to [github.com/new](https://github.com/new).
2. Name the repository: `balaji-portfolio` (or `yourusername.github.io` if you want it as your primary GitHub site).
3. Leave it **Public**.
4. Click **Create repository**.

### Step 2: Push Your Code
Run these three commands in your terminal from this directory:

```bash
git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/balaji-portfolio.git
git branch -M main
git push -u origin main
```

### Step 3: Enable GitHub Pages
1. Go to your repository on GitHub.
2. Click **Settings** (top right tab) → **Pages** (on the left menu).
3. Under **Build and deployment > Branch**, select `main` and `/ (root)`.
4. Click **Save**.

Your portfolio will be live in ~60 seconds at:
`https://<YOUR_GITHUB_USERNAME>.github.io/balaji-portfolio`
